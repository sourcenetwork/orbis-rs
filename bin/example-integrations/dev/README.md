# Local reference environment

This directory is reserved for shared Orbis ring and ACP startup configuration,
bootstrap scripts, and public development fixtures.

Node startup is not implemented in this scaffold. The future reference setup
should exercise a real policy grant and denial as well as the threshold result.
Any isolated demo using permissive or mock authorization must say so explicitly.

Use the Orbis implementation and Vera revisions selected by the root workspace
when connecting the first example. Configure the ring's committee and threshold explicitly, and keep
service endpoints and application configuration outside the reusable verifier core.
