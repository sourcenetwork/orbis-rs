Passkey-authorized threshold signing

Reference app for Orbis's passkey-sign integration. Register a passkey, then use it to authorize a threshold Sign request against a running orbis-node ring — no JWT, no password. The passkey's own public key is the identity ACP grants or revokes; this page never verifies anything itself, every ring node does that independently.
